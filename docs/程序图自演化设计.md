# 程序图自演化接入

## 不变量

- PG 只提供下一步行动建议，不执行工具、不改变权限、确认、预算和独立审查。
- 每次 Run 绑定不可变图及其指纹；恢复必须使用同一图。指导模型通过现有 Runtime / Gateway 计费和持久化，重复构建上下文或恢复不得重复消费已完成的指导调用。
- 图包含可复用程序知识，不保存具体商品、订单、个人偏好或凭证。自由文本检查只是辅助门禁，硬约束仍由 Kernel 执行。
- 学习和选择都只能使用 dev，且按 case 分成互斥训练集和验证集。test 只在图冻结后用于最终对照。
- 结构合法不代表有效。每次提案保留原文、修改、来源轨迹、候选图、验证结果及拒绝原因；验证不退化才保留。保留不等于产品晋升。
- 种子图、演化图与无 PG 基线分别评测，指导调用的 Token、延迟、失败和预算跳过都计入真实成本。没有真实模型对照，不宣称收益。

## 论文映射

来源：[Procedural Graphs](https://arxiv.org/abs/2609.09153)，本地 PDF 为 2026-09-08 的 v1；[作者代码](https://github.com/YuxingLu613/Procedural-Graph/tree/9667bdc5f3fce89809429f9ce20188e3e989b9b3)，核对 core.py、retriever.py、refinement.py。实现复用项目依赖，不引入作者的 Vertex 客户端或平行执行器。

图用节点及带 condition / guidance / pitfalls 的有向关系表示。在线定位最近行动，读取向外两跳子图及最近三步轨迹，由独立指导模型生成情境化建议，送入原 adaptive 决策。无法定位时回退全图；上下文无法容纳时明确跳过，保留原决策与核验所需空间。条件是供模型理解的文本，不是可执行表达式。

离线 Refiner 根据当前图的训练轨迹提出节点、边增删；更新属性用删除后添加。候选在独立 dev 验证集上与当前保留图比较，同分或改善且安全/协议不退化才接纳。拒绝记忆参与后续提案，失败候选和原始报告保留。

LingCart 适配：行动节点受已有只读工具与决策协议词表约束；允许恢复循环，但每个节点必须能到达显式 End。图在 Harness 的 context 槽位装配；独立审查不接收 PG。在线每次指导预留后续决策与核验调用，预算不足时记录跳过，不把声明绑定当作实际使用证据。
