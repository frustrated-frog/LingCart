# 语义与业务效果贯通修复

## 必须保持的不变量

- 执行禁令在审批、preflight、账本重放和副作用之前检查；复合工具声明全部业务效果，禁止退款不禁止本地草稿。
- 所有合法目标 ID 均可无损投影，不改变大小写、不合并不同身份。
- 模型表达目录概念，可信注册表负责执行编码；旧持久化契约仍严格验证，冲突编码不能被静默接受。
- 售后用户陈述不等于政策满足；每项更新保留原文、版本与幂等身份，模型核验在写事务外。
- 跨轮新任务或材料更新不解除已有禁令，局部更新不重复提交已完成的副作用。
- 历史 PG 测试集已成为诊断回归，不再用它宣称未见泛化或论文收益。

## 已实现

1. ToolSpec 新增业务效果，支付、退款和最终提交仍要求审批；复合售后工具显式声明退款效果。限制检查仍先于 preflight 和账本重放。旧审批动作由兼容映射补齐效果，新工具应显式声明。
2. RequestIR 接受上游合法大小写目标 ID，原样保留，不改变既有小写身份。
3. 模型条件协议区分目录概念与原始谓词，概念路径不再要求重复输出 field/op/value；宿主填入未绑定形态，后续仍根据实际目录观测绑定并校验。旧持久化或显式冲突编码不被自动覆盖。增加 PD 功率单位编码。
4. 售后入口复用 request-semantics/v1 的独立提取与显式修订，新增 after_sales_case 结果类型和 reason_code；独立检查订单、原因与目标数量。材料事实/未知可以参与请求覆盖，不会成为额外建案目标或政策满足凭证。原有售后单测隔离提取模型，新入口由独立响应专项测试验证。
5. evidence_updates 将同一案件的一轮多项更新编译成顺序步骤；每项有独立工具账本，后项绑定前项提交版本。补证核验在事务外，提交前仍核对案件、政策及证据版本。中断后重放已完成项，不重复写入。
6. 多项更新投影为 RequestIR 的 USER_FACT；独立需求契约通过原 RunResult 字段返回，控制台可读取真实状态。明确禁止提交时，完成草稿后停止生成审批，不把正常草稿任务标为退款执行失败。
7. 真实模型发现的冗余元数据错误通过缩小生成协议修复：固定目标类型由注册表确定，证据策略仅暴露能力声明的可选枚举。旧冲突输入继续拒绝。压缩重复说明，保持原上下文及模型预算。

## 范围与限制

- 批次遵守既有步数、深度、工具和模型预算；不扩大预算以容纳任意长批次。失败后保留已提交项，停止其依赖项；不是跨多个工具的大事务回滚。
- 独立售后提取当前核对业务结果及执行限制；材料充分性仍由现有政策与独立证据核验承担。没有声明自然语言理解必然正确。
- 没有新建 Planner 或平行 Runtime，没有新增数据库表、第三方依赖或 UI 页面。
- 旧 PG 测试题仅用于已见诊断，不构成新一轮 PG 收益评测；Refiner 学习收益仍待后续单独验证。

## 验证约定

- 新增独立结果不能替规划器覆盖遗漏的附加业务目标；同一轮修复复用独立提取缓存。新模块纳入 Harness 源码指纹。
- 真实回归入口：`PYTHONPATH=. venv/bin/python research/experiments/semantic-effects-diagnostic-20261031/run_smoke.py`。仅运行 PGE-T01、ASA-D01、ASE-D01 各一次，沿用原判分，逐份保留原始报告；后两题使用对应售后研究 Profile，不改变产品 Profile。
- 诊断限制与运行时原上限取较小值，每次模型调用最多一次 Provider 尝试。固定种子业务库按样本隔离；不触碰实际业务数据库，不发送真实支付/退款。

## 自动化验证结果

- Python 最终完整套件：1135 passed。
- 固定离线任务 Gate：60/60 任务、71/71 轮通过；仅脚本模型，不代表语言理解成功率。
- React：78 项测试通过；TypeScript 类型检查、生产构建通过。构建仍有既有的大体积 chunk 提示。
- 新增用例覆盖复合退款禁令、大小写目标 ID、概念协议及冲突拒绝、PD 单位、独立售后订单不一致拒绝、多材料版本绑定、中断恢复、重复请求、仅草稿不审批，以及附加目标遗漏拒绝。

## 真实模型诊断结果

首轮 3 题各一次，2/3 通过；售后元数据错误修复后，仅对失败题复测一次，1/1 通过，停在退款确认之前。原始失败没有覆盖。记录位于 `research/experiments/semantic-effects-diagnostic-20261031/诊断回归记录.md`，包含两轮源码版本、预算、Token、报告及 SHA-256。

这验证了具体样例上的修复可用性，不证明任意复杂任务准确率或 PG 收益。多材料自然语言理解与学习后图结构收益仍需另行评测。
