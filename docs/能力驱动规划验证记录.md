# 能力驱动规划验证记录

日期：2026-11-06。分支：`codex/capability-grounded-planning-v1`，基于当时最新 `origin/main` 的 `c0d4478`。

## 行为验证

- 复合目标通过真实 SQLite 工具取得订单详情、退款资格和商品结果，最后进入既有目标核验与独立审查。订单详情产生的状态可供同一订单退款资格查询复用，不再要求额外固定状态查询。
- 两个订单的观察隔离；空商品集、业务失败、缺少字段和目标不一致均不建立预测事实；有效否定结果仍是可用观察。
- 某个前置生产者失败时搜索其它生产者；不可达、节点/步数预算耗尽分别呈现。独立目标能够继续推进。
- 工具结果提交后中断，通过持久化账本恢复同一 pending 动作，保留原步骤和依赖来源。
- 用户更新目标后，旧观察不满足新规划，历史计划也不注入新目标理解。
- 产品入口拒绝 `adaptive-cgap-v1`；只读规划不包含支付、退款写操作。

在 1440×1000 与 1280×900 桌面尺寸检查运行检查器的“能力规划”页：8 个真实计划版本可切换，依赖边、节点选择、实际观察来源与历史状态提示可见。修复了全局按钮规则对节点排版的干扰及 SVG 选择器影响图标定位的问题。1280 宽度下页面没有横向溢出，依赖图按自身容器滚动；页面控制台没有错误或警告。

验收服务 `/health`、`/ready` 返回 200，规划 API 返回 8 个有效版本。截图位于本地忽略目录 `output/playwright/`，临时数据库和截图不进入 Git。
