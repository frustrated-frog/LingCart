# 研发证据工作台动效设计

## 目标

“研发与证据”页面需要像可审计的科研仪器，而不是通用后台或营销展示页。视觉升级服务于三件事：快速识别系统状态、理解执行与实验的空间关系、在切换证据时保持上下文连续。所有指标、状态和覆盖率仍来自真实 API；动效不生成业务事实。

本次覆盖工程总览、运行检查、论文实验室、机制与配置、评测数据集五个页面。消费工作台继续使用原有明亮视觉系统，两套页面只共享产品基础，不共享装饰风格。

## 开源选型

- [Motion](https://github.com/motiondivision/motion)：MIT 许可，用于弹簧、共享布局和进入/退出编排。通过 `LazyMotion` 动态加载 `domMax`，避免把完整动效运行时并入首屏主包。
- [NumberFlow](https://github.com/barvian/number-flow)：MIT 许可，只用于真实数值投影的连续变化，不用于伪造实时刷新。
- [Motion Primitives](https://github.com/ibelick/motion-primitives)：作为可组合动效原语的参考；当前没有复制组件源码，避免引入第二套组件约束。
- [Langfuse](https://github.com/langfuse/langfuse) 与 [Phoenix](https://github.com/Arize-ai/phoenix)：参考其可观测性产品的信息分层，将运行、事件、机制和评测证据保持为可追溯结构。

没有直接采用 Magic UI 或 Aceternity 一类以营销视觉为主的整套组件。研发页面只吸收克制的信号、材质和层级表达，避免持续发光、大面积漂浮背景或与数据无关的装饰动画。

## 视觉系统

- 画布：冷白实验台，使用静态网格与局部径向光晕表达空间，不移动整页背景。
- 结构：深墨色工程导航负责稳定定位；白色半透明卡片承载状态与证据；深色仪器面板承载系统主张和机器数据。
- 信号色：蓝色表示当前交互，紫色表示候选或差异，薄荷绿表示连接与正常状态。错误、警告继续使用业务语义色。
- 卡片：统一高光边、细描边、低扩散阴影和 17–18px 圆角；悬停只抬升 2–4px，不让内容漂浮失控。
- 密度：标题承担页面定位，编号与等宽标识承担证据定位，卡片内部保持高信息密度。

## 动效语法

- 页面与视图切换采用短距离、临界阻尼弹簧；不使用长缓动或弹跳。
- 标签页、执行事件与配置差异使用共享布局高亮，保留“同一对象移动”的连续感。
- 卡片组按 45–65ms 轻微错峰进入，单次出现后保持静止。
- 数值只在后端投影发生变化时滚动；空态、失败态与历史报告不会获得“成功”动效。
- 按压反馈保持在约 0.97–0.985 的缩放范围，悬停位移不超过 4px。
- 读取状态使用局部轨道点，不在视口中心制造永久旋转器。

## 可访问性与性能边界

- `MotionConfig reducedMotion="user"` 遵守系统减少动态效果偏好；CSS 同时移除位移、模糊与循环动画。
- `prefers-reduced-transparency` 关闭关键区域的玻璃模糊并恢复实体背景；高对比偏好提高描边和文字对比。
- 标签页仍为真实按钮并保留 `role="tab"`、`aria-selected` 和可见焦点；动效容器不替代语义元素。
- 动效特性独立为异步分块。主包不包含完整 `domMax`，研发页首次需要时再加载布局动画能力。

## 运行检查事件流

运行检查使用“输入命令 → 持久事件流 → 事件探针 → 运行输出”的单向证据结构。执行主脊是页面唯一的高对比动态区域：深色仪器带承载真实事件序列，节点颜色区分模型、工具、证据、终态和错误类别；当前节点的定位值和探针内容都由用户选择驱动。

- 鼠标选择节点时，使用 240ms 内的一次性扫描和临界阻尼共享布局高亮，随后保持静止。
- 方向键、Home 和 End 支持高频浏览；键盘路径不播放扫描或平滑横移，探针即时更新。
- 横向自动定位只滚动事件容器，不改变页面纵向位置；事件很多时保持当前节点居中并露出相邻上下文。
- 浏览定位进度使用 `transform: scaleX()`，不通过 `width` 触发布局动画。
- 事件类型、序号、时间戳、载荷字段数和协议标识均来自真实事件；网格、扫描光和材质仅用于空间表达，不冒充遥测数据。

## 验收边界

- 五个研发页面在 1440px 与 1728px 桌面视口下无横向页面滚动。
- 页面切换、运行事件选择、详情标签页、实验与数据集切换都有连续反馈。
- loading、empty、error、partial、stale 或历史结果继续表达真实状态，不能被装饰遮盖。
- 消费工作台不继承研发侧的深色导航、网格背景和仪器卡片样式。
- 类型检查、组件测试、生产构建和真实浏览器控制台检查必须通过。
