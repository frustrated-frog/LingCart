# 程序图信息增益与公平对照修复

## 必须保持的不变量

- 新步骤、重新读取时间、返回顺序和查询词变化本身不构成信息增益。
- 可信来源中新增对象、对象内容或来源版本变化可以构成信息增益；失败、未完成与缓存重放不能产生新观察奖励。
- 步骤身份继续用于恢复与审计，学习依据使用内容身份；同一信息换一个证据引用不能再次获奖。
- 执行事实与信息增益分开记录。历史快照无法比较时保持 UNKNOWN，历史事件不回写、不作为新版正向学习依据。
- 目标核验按目标身份比较，不能只比较计数；参数映射按内容比较，不能只比较修订号。
- V3/V4 的研究对照使用同一不可变图，现有默认 Profile 及历史实验保留；正式实验使用新版本契约。
- 所有条件和工具权限仍由既有 Runtime 处理。本次不启动计费评测、不调整留出集。

## 观察身份

商品观察按来源、商品身份和记录内容归一化，搜索/对比返回的相同商品共享身份；查询回显、总数和排序不作为商品信息奖励。保留业务字段和来源版本，排除 Runtime 附加的 observation 包装。非商品工具按工具、有效参数和来源区分观察范围，比较去除 Runtime 包装后的完整结构化内容。

快照保留每个观察范围最后一次成功执行的内容摘要，因此价格变更后又恢复旧值也能识别为当前事实变化。REUSED 不刷新当前观察。归档读取只引用原始证据，不制造新事实。摘要不保存商品、订单正文。

信息增益是结构化变化的保守代理，不是语义新颖性或因果贡献证明；没有可信版本或有效性变化的同内容刷新不奖励。跨不同非商品工具的语义等价尚不自动合并。
