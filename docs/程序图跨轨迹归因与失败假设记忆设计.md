# 程序图跨轨迹归因与失败假设记忆设计

## 范围与不变量

本轮在 V4 在线机制上增加可替换的离线 `credit-memory-v1` 演化策略。保留 `basic-v1`，不改变工具执行、权限和产品 Profile，不实现 Critic、Pruner 或源码自修改。

- 贡献分析只读取已验证的冻结训练 dev 报告；验证集只用于选择，测试集不能进入提案或记忆输入。
- 按图及边内容身份连接条件、曝光、采用、信息增益和后续目标核验。成功任务不能整体奖励，失败任务不能整体惩罚。
- 只有条件 TRUE、真实曝光、已采用且具有新版信息增益的行动产生支持证据。重复观察产生反例；缺事件、旧进展协议、条件未知、未采用及不可归因的工具失败保持 UNKNOWN。
- 同任务成败对照是关联分析，不是因果估计；没有成败对时明确缺少对照，不制造贡献分数。
- 每轮贡献报告、假设、Patch、验证摘要、失败记忆均不可变落盘，失败和取消不删除已产生的产物。
- 失败假设按同一父图、目标关系、失败类型和预期变化归一化；更换理由文字不能绕过已被验证否定的方向。基础设施失败不封禁假设。
- Refiner 只获得训练证据和验证聚合反馈；具体退化验证案例供 UI 审查，不能回流提案输入。
- V5 冒烟仅运行训练与验证开发样本，固定低预算，不触碰测试集；正式算法比较必须固定同一个 V4 在线配置及种子图。

## 界面

沿用实验台现有绿色、灰白与等宽数据字体，不新增配色体系。图边详情下显示支持、反例、未知三类证据；每条证据可打开训练原始样本。轮次详情展示修改假设、预期行为、验证退化与拒绝记忆。旧记录显示“未记录”，部分结果仍可审查；测试替身和真实模型来源明确区分。

## 研究边界

这是 PG 的贡献与失败记忆增强，不是完整复现 RRSI。图结构仍通过现有 Validator 和独立验证 Gate 选择，接受仅表示验证未退化；没有新的留出重复对照就不宣称收益。
