# 执行图回放工作台

## 目标与视觉选择

面向检查 Agent 行动的研究与工程人员，让一个时间游标同时控制事件邻域、历史程序子图与原始证据。主视觉是一台可回拨的执行仪器：顶部显示记录来源，中央画布，右侧证据探针，底部事件带与播放控制。

配色使用深海底色 `#101c2d`、节点底色 `#1a2a40`、浅字 `#e5edf8`、当前记录青色 `#64dfdf`、候选紫色 `#b29cff`、阻断琥珀 `#f2c078`。核验记录保持独立文字语义，不把节点绿色等同于整个任务成功。中文沿用 LingCart Sans / PingFang SC，编号与身份使用 JetBrains Mono / SFMono-Regular；标题 20px、正文 13px、数据标签 11px。

审视后舍弃通用监控大屏的装饰指标、旋转粒子与持续流光。独特交互是“证据游标”：拖动时间刻度时，同步显示当时的 PG 局部图，尚未发生的结果不进入探针。线条表达真实记录关系，动效仅回应选择。

## 不变量

- 不改 Runtime、接口或实验判定；前端只做已有事件和冻结图的展示适配。
- 事件带按 API 返回的存储顺序浏览，保留真实 sequence；缺失编号不伪造。事件连线仅表示记录先后，不声称因果或工具成功。
- PG 回放只使用游标之前最近一次 `pg_guidance.subgraph`，显示原始图身份与指纹；没有快照时显示空态，不套用当前 seed 或 retained 图。
- PG 指导选中关系、预演关系和实际工具事件分别标识；只有原事件携带的事实进入详情。高亮不构成因果收益声明。
- 播放按照可调事件间隔推进，不声称恢复真实耗时，不触发模型或工具。切换运行、样本、轮次停止播放；手动跳转停止播放。
- 图布局失败保留节点和关系的可访问列表；轮询错误保留已有证据并显示过期提示。大事件流用固定邻域画布与事件滚动带，避免将所有事件强塞进一屏。

## 依赖

- `@xyflow/react`（MIT）：画布、缩放、平移、节点与关系选择、键盘操作。使用开源核心，不依赖付费示例。
- `elkjs`（EPL-2.0）：有向图自动布局。通过动态导入隔离体积，布局失败回退为可浏览节点列表。
- 复用现有 Motion 与 CSS 体系；不引入 Tailwind / shadcn 或装饰性组件集。减少动态效果偏好下取消过渡。

## 验收

覆盖无事件、缺失局部图、部分历史数据、重复编号、播放终点、手动跳转与运行切换。用本地真实运行和历史 PG 样本检查桌面布局、缩放、边选择、时间跳转及事件证据联动；不运行计费实验。图版本差异对比与并排实验轨迹留给后续阶段。

## 视觉验收后的调整

长链条不能只依赖 fitView 缩到一行。ELK 先确定分层，再将过长的横向层折成三列蛇形布局，保留同层间距与原始关系。跨层线在节点矩形外侧寻路，避免穿过其他节点造成语义误读；寻路网格设有规模上限。普通执行图在较窄桌面画布中展示两个相邻事件，较宽时展示三个，完整轨迹仍由时间轴访问。

图节点与关系支持 Enter / 空格选择。检查 PG 对象时暂停播放，避免证据在阅读中被下一帧替换。快照过滤了重复对象或缺失引用时显示部分数据提示。
