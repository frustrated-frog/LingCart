# 程序图挑战实验台

本阶段验证程序图能否改变后续任务的行动选择。入口为论文实验室内的 PG 实验台；保留原有实验契约页。

## 必须保持的不变量

- 训练、验证、测试按任务情境族隔离；只有训练轨迹进入 Refiner。测试在最终保留图冻结后执行，不能反馈到学习。
- 三组使用同一数据、模型、运行预算与源码，唯一主变量是上下文：无 PG、种子图、演化保留图。没有接受任何修改时，明确显示保留图仍为种子图。
- 图、提案、拒绝记录、原始样本和报告不可覆盖。研究状态持久化；相同请求重试不会再次启动模型调用。
- 评测在独立子进程运行，使用临时业务数据库；不在 HTTP 进程内修改工具注册表或生产数据库。
- 中断不自动重跑计费调用；保留已落盘样本并标记中断。任务完成与通过实验门禁是不同状态。
- 机制保持 candidate，不晋升产品。测试替身、冒烟结果、未完成报告都不能作为机制收益结论。
- 所有模型调用仍走 Gateway / Runtime；单 Run 16 次，Refiner 每轮 2 次。启动前展示最大样本及调用预算。

## 任务与指标

挑战集分为 train / validation / test 三组，每组 6 个情境。覆盖空结果恢复、工具选择、行动依赖、多目标覆盖、环境变化和组合迁移。广义能力可以跨组，具体情境族与请求不得跨组。首版为人工构建的小型工程挑战集，不能代表广泛泛化能力。

成功率沿用独立结果判据；扰动恢复率只统计实际触发故障的样本；重复无效调用统计同一轮内参数相同且返回相同空结果或错误的重复工具调用，不把正常重复读取当作无效。PG 暴露率来自 mechanism_applied 事件。Token 缺报时为未知，不补零。延迟与训练开销单独展示。

冒烟使用一次重复、一次演化；正式配置使用三次重复、三次演化。全部阶段按冻结顺序执行。最终比较检查完整样本、身份和环境一致、独立判分、安全协议、指导暴露以及调用成本。成功率提高且通过保护条件才可标记观察到改善；平局只代表本批次无退化，不能声称统计显著性。此台不自动执行产品晋升。

## 界面

桌面工程工作台：顶部为实验身份和启动预算；中央三列对齐无 PG / 种子图 / 保留图；下方为可选演化轮次、节点/边修改和逐样本失败证据。沿用现有墨绿、蓝紫与等宽数字；避免用装饰性的指标块抢占图修改的阅读空间。

真实空态、读取失败、已有数据刷新失败、执行中、部分产物与历史指纹变化分别呈现。图关系以可读的节点连线和条件/指导/常见错误表展示，并保留原始 JSON。启动采用幂等请求；停止请求在当前有界模型/样本完成后生效，不自动恢复。

## 使用与产物

从「论文实验室 → PG 自演化实验台」进入 `/experiments/pg`。建议先选择冒烟：最多 6 个任务样本、50 次模型尝试；完整配置上限为 180 个样本、2886 次模型尝试。上限包含 Run 重试和 Refiner，不是预计用量；提案无效或被重复拒绝会跳过对应验证。尚未配置模型时不可启动。

- `output/pg-lab/jobs.db` 保存实验身份、幂等请求、阶段进度、停止请求与结果投影。
- `output/pg-lab/<job_id>/` 保存冻结配置、原始样本、各阶段报告、测试契约与比较结论。
- `research/graphs/pg-lab/<job_id>/` 保存不可覆盖的图、Profile、提案、拒绝记录及最终保留图；这些运行产物不提交 Git。
- 工程 API 位于 `/engineering/pg/`，继承 Engineering Key / 回环访问限制；写接口额外校验网页 Origin。启动请求必须提供幂等 `request_id` 和 `smoke` 或 `full` 配置。
- 工作进程每 10 秒续约，超过 90 秒无心跳标为中断，不自动重跑。停止在当前有界样本结束后生效。部分样本仍可从实验台打开。

空结果故障注入保留物理工具返回、调用参数和注入观察。判分只接受与物理记录匹配的单次预定义空结果变换；其他变换被拒绝。搜索与候选发现都可触发该故障，题目不直接提示恢复策略。价格、库存与运行中需求变更也由同一个隔离评测环境触发。

目前验证包括接受/拒绝提案、三组执行顺序、dev/test 隔离、幂等与并发启动、进程中断、停止后证据、注入来源核验、工程 API 拒绝路径和 UI 状态。桌面浏览器使用隔离测试账本检查图版本、边选择、差异记录和样本展开；明确标记 `test_harness`，不是模型收益证据。尚未运行真实模型效果对照。
