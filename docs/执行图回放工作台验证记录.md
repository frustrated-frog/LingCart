# 执行图回放工作台验证记录

日期：2026-10-31。分支：`codex/execution-graph-workbench`，从同步后的 `origin/main` 创建。

## 使用入口

- 运行检查：选择任意已有 Run，在“执行现场”单步、播放、拖动时间轴；点击节点检查当前事件。运行期间可以主动开启“跟随最新”。
- 历史程序图：使用游标之前最近一次指导事件的局部图，查看图身份、指纹与指导关系。没有对应快照时显示空态。
- 论文实验室 → PG 自演化实验台：查看种子、保留、训练图的交互画布。选择边后，下方原有条件说明与贡献面板同步更新。
- 样本证据：点击查看样本，再选择回放轮次；原有干预链和失败原因继续保留。

## 实际限制

- 回放按事件间隔推进，不复原真实耗时；局部图只有历史已记录的关系。
- ELK 独立按需加载包约 1.46 MB（gzip 452 KB），首次打开程序图需要加载。构建仍报告大包提示，未通过调高阈值隐藏。
- 本阶段没有图版本差异着色或双轨迹并排比较。
- 验收中发现既有生产路由 `/runs/{id}` 与业务 API 重名：直接刷新详情地址会返回要求 `session_id` 的 API 错误；从 `/runs` 入口进入正常。该既有路由问题未混入本次可视化改动。
