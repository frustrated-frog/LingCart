# 持续自改进记忆设计

## 目标与实现前不变量

借鉴《Self-Improvement Memory Enables Continual Recursive Self-Improvement》（本地版本 2026-11-13），在现有 PG V4 离线演化器上接入 `sim-v1`。本轮不接 SOMEM、不修改 Stable Kernel、不训练模型权重，不开放 Harness 源码自修改。

- 复用 Refiner、GraphPatch、贡献报告与独立验证 Gate；SIM 只影响候选提案，不能代替验证选择或放宽权限。
- 问题身份独立于父图；尝试仍绑定父图、候选图、模型、数据、预算、源码和训练报告身份。跨环境失败是历史经验，不能自动成为永久禁令。
- 预期修复案例在候选评测前冻结，仅引用当前训练失败样本；候选在相同训练案例上额外复测，记录修复、未修复及新增退化。验证案例明细不进入 SIM。
- 记忆只包含 dev 训练引用、策略与验证聚合反馈，不保存业务事实。来源不符、图身份不符、记录篡改、训练数据流入目标验证分组均拒绝继承。
- `none / problems / full` 三种条件共享在线 V4、起始图、提案协议、训练复测、预算和 Gate，只改变优化器读到的 SIM 内容。完整审计产物始终保存，不将对照条件误写为没有发生历史尝试。
- 实验启动冻结来源任务、记忆快照及指纹，重试不重新读取来源或重复计费。只允许完成的 SIM 任务作为 UI 继承来源；失败和取消记录仍保留供审查。
- 固定训练、验证及未使用的最终留出集；本轮实验台仅运行 dev。测试集不参与选型、学习或停止判断。产物始终为 candidate。
- 不静默裁剪记忆；数量及上下文有界，达到上限明确失败。全部新增评测计入既有总预算。

## 与论文及既有机制的区别

原论文优化 Harness 代码并让提案者和选择者读取 SIM；本实现先限定修改对象为 PG 图，选择继续采用现有确定性 Gate。原论文主要保存被选择的修改，本实现沿用项目要求，同时保留合法但被拒绝的尝试及其原因。它是 SIM 设计思想的受限工程适配，不是论文完整复现。

原有 `credit-memory-v1` 保持兼容；其单次任务内的拒绝记忆与 SIM 的跨实验问题历史分开。跨实验不继承局部黑名单。SIM 继承必须携带最终保留图；不能把记忆直接附加给不相关种子图。

## 验收

覆盖冷启动、两次独立演化继承、三种信息条件、预测落空、验证退化、无效来源、快照隔离、幂等冲突、错误/取消保留、成本预算和旧记录兼容。UI 展示来源、条件、问题、逐次修改与预期/实际差异，测试替身显式标记。真实模型迁移收益另行预算与冻结对照，本轮不调用计费模型。

## 实现与使用

实验台 `/experiments/pg` 新增“持续自改进记忆 · SIM”。选择记忆条件后可冷启动，或从已完成的真实 SIM 任务继承保留图与记忆。实验是显式计费入口；本次开发没有启动真实模型请求。测试替身记录可查看，但不能作为真实实验的继承来源。

界面按问题展示跨实验时间线，包含修改内容、预测样本、实测修复／落空／退化、验证聚合反馈、环境指纹和来源跳转。中断任务只显示已完成轮次；未评测明确显示未知。三条件使用相同评测与预算；同源三臂的自动汇总评测器尚未实现，不能据单次实验宣称收益。

CLI 支持 `--sim-source <sim-memory.json>`，须同时传入相应 `--base-graph <retained.json>`。不带 `--live` 只校验；SIM 不生成旧版 PG 的测试对照契约。完整记忆输入超过既有 Refiner 上限时返回 `REFINER_CONTEXT_TOO_LARGE`，不静默缩减为部分历史。

## 验证记录（2026-11-21）

- Python 完整套件：965 项通过。
- 固定离线任务 Gate：60/60 任务、71/71 轮次通过，只使用脚本模型。
- 前端：68 项测试通过，TypeScript 检查与生产构建通过。构建仍提示既有主包大于 500 kB，未引入新依赖。
- 真实浏览器：使用隔离 SQLite 数据库与 JobStore，经 worker 生成并明确标记 `test_harness` 的两次 SIM 实验；通过真实 API 展示。检查桌面布局、继承来源跳转、展开修改详情、预测修复但验证拒绝、历史环境变化提示。`/health` 与 `/ready` 正常，模型就绪只检查配置。
- 浏览器暴露并修复继承记忆响应的数组／元组严格校验问题，补齐 GET 与幂等 POST 回归。
- 一次并行验证因开发期间源码变化触发 `PG_IDENTITY_CHANGED` 而中止；稳定源码后完整重跑通过，未削弱身份校验。

限制：当前是优化 PG 的离线 SIM 适配，未接入 SOMEM、未开放源码自修改，未运行真实模型三条件对照或跨模型收益评测。所有产物保持 candidate，产品默认 Profile 不变。
