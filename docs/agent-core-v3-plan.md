## 后续能力建设：复合目标与逐项完成核验

模型首次理解需求时必须显式声明逐项目标，运行时维护独立完成账本；选购、订单查询等任务的执行顺序继续由模型决定。复合任务通过 `complete` 为每个目标提交证据，执行层检查类型、对象、成功状态和需求版本。选购成功不再直接结束整个复合请求；最终完成前重新刷新推荐商品，失败交回模型。工作台 Agent Lab 增加逐项目标与证据视图。

检查点中的自主协议升级至版本3，旧版缺少目标契约时拒绝猜测迁移；原运行时快照协议、审批边界与控制并发契约不变。恢复时保留历史，重新核验商品，不重复执行已保存的普通查询；用户改变需求后重新建立目标账本。当前支持的完成契约限于现有只读业务能力，语义目标提取是否完整仍需后续真实模型验证。

本轮验证：全量 369 项测试通过；离线门禁 60/60 任务、71/71 轮通过。相对上一轮增加 24 项测试，覆盖复合目标漏项、证据类型和对象错配、独立推荐记录、最终刷新预算、查询期间数据变化、目标变更及中断恢复。模型均为脚本替身，未配置或调用真实提供方。
