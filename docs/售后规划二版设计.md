# 售后规划二版设计

本轮在模型规划 v1 基础上实现版本化 planning v2；保留 v1 作同版对照，不接入经验学习。

## 不变量

- 模型只能引用当前输入目录中 HUMAN 来源的片段 ID；宿主还原原文及消息身份，旧请求或其他案件的目录不能授权当前动作。
- 批量材料仍逐项经原有工具账本和核验链提交。只合并相邻、同案件、显式版本依赖的材料更新之间的规划；任一失败不得生成批次完成或提交确认。
- 恢复按冻结计划重放，已提交材料从工具账本读取；规划输入不得依赖重放产生的新事件号或 REUSED 状态。
- 上次决策按案件隔离，引用运行身份；仅作为历史选择供比较，不替代当前事实或授权。真实观察与模型预期分开保存。
- v1 的协议及运行方式保留。v2 保持 candidate；同批 baseline/candidate 使用同版源码、固定数据和预算，保留负结果。
