# 售后有限步前瞻

## 范围与不变量

- 新增独立原生候选 Profile，基线为 V5 主动澄清；不 promotion，不声称论文复现或真实收益。
- 在已验证义务图和澄清问题集合上精确枚举最多两步、最多十二个信息动作。枚举节点上限 144；超过候选上限显式回退 V5，不裁掉未知候选后宣称最优。
- 路径比较依次考虑：充分信息假设下剩余义务数、用户交互次数、工具次数、回答负担；平局优先低负担的第一步，再以稳定身份排序。权威查询优先级保持不变。
- 每个候选都保留充分信息与无有效信息两种分支。无概率、不预测用户、不执行模拟工具，不将预演写成证据或政策满足状态。
- 只执行首步；实际观察之后重新读取案件、政策和材料版本，再规划。延期、审批和不支持能力不能计作可自动消除的义务。
- 继续使用 ToolExecutor、PendingClarification、独立材料核验和原预算。恢复复用已提交工具账本。
- 前端显示持久化候选路径及来源版本；旧状态显示已过期，缺失记录显示空态，不拼造收益。

## 技术边界

当前政策义务是合取关系，候选信息动作各绑定一项义务。这一版是有限步、乐观信息覆盖与回答负担规划，不是概率世界模型，也不代表一般 POMDP 求解。前瞻的有效性需要同版对照与未见任务验证；PG 学习留到下一阶段。
