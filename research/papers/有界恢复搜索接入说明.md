# 有界恢复搜索接入说明

参考 [LATS](https://arxiv.org/abs/2310.04406) 的候选探索与环境反馈，以及 [Tree Search for Language Model Agents](https://arxiv.org/abs/2407.01476) 的环境内搜索。接入 planning 槽位，采用最多三个分支、两步深度的只读候选序列探查。它是受预算限制的工程适配，不是完整 MCTS，也没有学习价值网络。候选仅从研究入口运行，论文收益不能作为本项目收益。

研究假设：从相同失败检查点出发，真实读取后选择下一步，可能比单次决策降低无效行动。配对控制组保留相同的错误修正资格，仅关闭搜索。数据库与故障剩余次数在独立回放中冻结，模型随机性仍然存在。实现与边界见[有界恢复搜索与同状态回放设计](../../docs/有界恢复搜索与同状态回放设计.md)。

v2 工程适配引入无需额外模型调用的失败门控与从注册工具派生的严格候选协议。新对照在相同 v2 协议下仅改变触发阈值，不把协议和门控同时变更后的差异归因于门控。它是本项目的资源调度假设，不声称是上述论文已验证的结论。见[恢复搜索门控与严格候选协议](../../docs/恢复搜索门控与严格候选协议.md)。
