# CGAP 能力驱动规划接入说明

论文：[Capability-Grounded Agentic Planning](https://arxiv.org/abs/2610.41040)，2026-10-29。
原文机制：工具目录确定性编译为 PDDL，模型提取终端操作，经典规划器搜索依赖，执行模型绑定具体对象与参数，实际观察更新状态，独立核验交付。领域前置条件由应用提供，论文没有实现从自然语言自动学习全部业务规则。

## 本项目的工程适配

- 扩展槽位为 planning，Profile 为 `adaptive-cgap-v1`，基线为 `adaptive-v1`。
- 使用有界 BFS 搜索声明式前置条件、增加效果与删除效果；当前只读能力不产生删除效果。没有引入外部 PDDL，也不声称完整复现作者实验。
- 能力契约归已有 `CapabilityRegistry` 注册管理，CGAP 不维护第二份工具目录。固定退款编译从同一声明展开默认依赖，CGAP 的新增部分是替代路径搜索、实际观察复用与滚动重算。快速路径复用现有能力编译器；没有另建工作流或执行器。
- 订单状态、详情、物流、支付状态、退款资格和政策回答可以绑定已接受目标中的参数；有可靠参数和已满足依赖的步骤直接进入既有 ToolExecutor。
- 商品检索与对比仍由模型选择参数；规划器提供候选获取依赖，并在执行前检查前置观察。商品候选就绪不是推荐完成，推荐与跨目标完成仍走既有核验。
- 真实观察按订单或问题隔离。不同订单不能共享状态证据。当前只按字段可用性建模，不推断政策适用性或退款授权。
- 发生失败后不自动重复同一确定性调用；可以从其它已注册生产者取得前置信息。没有替代路径时明确展示不可达；开放式恢复继续交给模型。

该版本没有增加“按原商品自动理解全部替代要求”或多商品总预算的新语义能力，也没有将售后规则变成可学习规则。它扩展的是已有目标协议内的工具依赖组织与执行能力。

## 可复现入口与结论范围

`research/experiments/capability-grounded-planning-v1/experiment-spec.json` 冻结唯一 planning 变量、3 次重复和成本保护指标；任务集为 `eval/cgap_tasks.json`（dev 3 项、test 5 项）。

可先执行不调用模型的预检：

```bash
venv/bin/python eval/run_adaptive_eval.py --dataset eval/cgap_tasks.json --dry-run
venv/bin/python -m pytest tests/test_capability_contracts.py tests/test_capability_planning.py -q
```

真实模型对照使用现有 `eval/run_adaptive_eval.py` 的 `--harness-profile`、`--experiment-spec`、`--baseline` 与 `--gate` 参数。基线和候选必须使用同一源码、数据、模型、预算与重复次数；按实际 API 预算显式启动。本轮不运行真实计费评测，不宣称成功率提升，也不自动晋升 Profile。

运行检查中的“能力规划”页读取持久化规划事件和检查点，展示计划版本、依赖、真实观察来源、待绑定参数与未覆盖目标。未来节点是待执行计划，不是业务结果。
