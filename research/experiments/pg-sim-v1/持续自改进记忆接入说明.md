# 持续自改进记忆接入说明

来源：《Self-Improvement Memory Enables Continual Recursive Self-Improvement》，用户本地 PDF，2026-11-13 版本。

## 假设与适用范围

同一个优化器跨实验记住问题、曾尝试的修改与预期／实际差异，可能减少重复试错，提高新的规划或恢复策略的质量。问题身份独立于父图；环境指纹记录模型、数据、源码、评测协议和预算，提醒优化器历史结果是否来自其他环境。

本实现将 SIM 接到现有 PG Refiner，修改对象限定为 PG 图。已有在线 `adaptive-pg-context-v4` 保持不变。候选修改仍须通过独立验证 Gate。未实现论文的源码修改器与模型选择器，因此不能称为完整论文复现。

## 与既有机制的分工

ACE 提供任务策略经验；PG 负责状态条件下的程序性指导；`credit-memory-v1` 记录一次演化内的贡献和失败假设。SIM 为离线优化器补充跨实验的问题历史，既不向任务 Agent 新增一套检索，也不替换现有 Runtime。SOMEM 的自组织任务记忆留到独立阶段。

## 实验与产物

离线优化器对照契约位于 `research/evaluations/pg-sim-v1/experiment-spec.json`，与只支持在线 Harness 二元对照的实验目录扫描区分。启动任务将契约复制进冻结计划；`evolution-spec.json` 固定开发集配置。

- 三条件：`none` 不暴露 SIM，`problems` 只暴露问题，`full` 暴露完整问题及修改历史。三者均保存完整审计产物，均进行候选训练复测。
- 公平对照须从同一个完成任务的保留图、记忆快照和目标模型配置启动，不能把前一个对照臂的输出传给后一个臂。
- 实验台每次运行一个条件；不会自动得出跨条件收益。冒烟只有 1 轮、1 次重复，不支持效果结论。
- `sim-source.json` 保存继承输入；逐轮 `sim-input` 保存实际优化器可见内容；`sim-forecast` 在评测前冻结预期；`candidate-training` 保存复测；`sim-memory` 保存版本化历史。
- 修改失败、预测落空和验证退化都保留；跨实验失败不自动成为永久黑名单。验证明细仅供审查，不进入 SIM。
- 只允许完成任务继承。取消或失败任务保留已完成轮次、样本和原始产物，不自动重跑。
- 记忆有容量和上下文上限，超限明确报错，不静默裁剪。自由文本复用既有策略检查，但这不构成对任意文本安全的形式化证明。

当前只有离线工程回归证据，未运行真实模型实验。尚不能宣称提升成功率、准确性或持续自改进收益；正式收益评估需要新的未使用留出集。
