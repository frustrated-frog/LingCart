# PG 小规模独立效果评测

## 冻结问题

当前需求语义修复后的同一 Runtime 中，PG V4 是否提高正确完成率，dev 学习保留的图是否进一步提高成功率？本轮只评价 PG，不能据此判断 ACE、LivePlan 或全部论文机制。保持当前分支的实现作为被测版本，不调整生产 Runtime。

三组为 `adaptive-v1`、V4 种子图、一次 dev 学习后保留图。V6 的预演能力不混入本轮变量。PG 关闭组仍包含当前原生规划和独立核验。

## 数据和执行

2026-10-31 新编写 8 个单轮任务，属于虚构商品目录内的新约束组合，不能称为开放世界泛化。训练 2 题，验证 2 题，各执行一次；test 4 题，每题每组执行两次，共 24 个 test 样本。测试涵盖两款备选、两个品类目标、首次检索为空和检索后库存清零。预先用商品夹具确认扰动后仍有可行解。

所有任务禁止支付、退款及业务写入；预设环境扰动单独留痕。沿用独立人工约束判据、真实数据库核对和轨迹协议校验。完成率以完整判据通过为准，另报“声称成功但判据失败”，不能把安全拒绝算作成功。

每次任务 16 次模型调用、90 秒、256000 输入 Token 和 12000 输出 Token 上限，单次 Provider 尝试一次。Refiner 最多两次调用。最多 30 次任务执行、482 次模型调用；实际成本以原始 usage 为准。使用相同 Gateway 配置，保存模型、源码、Prompt、数据、依赖和预算指纹。按题轮转三组顺序；每个区块内两次重复连续执行，仍存在提供方时间波动。

## 学习与结论

`credit-memory-v1` 只读取两道 train 题，独立 dev validation 选择图；一次迭代后冻结。拒绝提案、失败样本、训练和验证轨迹均保留。若没有保留新图，第三组仍独立运行原图，必须明确标注为同图重复，不能宣称自进化有效。

`experiment-spec.json` 预先冻结指标方向和零回退门槛；动态图 ID 与实际 context 源文件在首次 test 调用前写入 `test-frozen.json`。成功率、首次通过率、两次均通过比例、安全、协议、模型调用和工具调用均不得回退。已有实验 Gate 采取严格成本非回退要求；dev 选择另允许每样本多两次调用，不能混淆两个门槛。

主要报告每题通过次数、总体正确完成率、错误完成数、扰动实际触发/恢复数、模型调用、Token、延迟和 PG 执行证据。使用现有 Gate 辅助审查，保持 candidate，不凭这个小样本晋升。4 题两次重复不支持统计显著性或普遍准确率承诺。test 开始后不修改被测源码、不调图、不丢弃失败或只挑最好结果。
