# PG 贡献归因与假设记忆 v1

## 冻结变量

候选使用 `evolution-spec.json`（`credit-memory-v1`），控制使用 `baseline-evolution-spec.json`（`basic-v1`）。两者均固定 `adaptive-pg-context-v4`、`research/graphs/pg-seed-v2.json`，训练 PG01–PG06，独立验证 PG07–PG12，各重复三次、三轮演化。唯一主要变量是离线提案与拒绝记忆策略；不改变在线 Runtime、图初始知识或任务集。预算字段在两份契约中完全相同。

实验台的“贡献与假设记忆”仅运行 dev 学习闭环：冒烟固定 PG01 训练和 PG07 验证，一轮一次重复，最多三个任务样本、26 次模型尝试、211500 token unit；完整 dev 学习最多 126 个样本。测试分组始终为空。

同任务成败对照要求同轮重复执行同时出现成功与失败。没有配对或没有完整的条件—采用—信息链时保持 UNKNOWN。单次冒烟不保证出现配对，也不证明学习收益。

## 如何复核

`iteration-XX-credit.json` 保存每条边的内容指纹、支持／反例／未知及样本引用；`iteration-XX-memory-input.json` 保存本轮实际收到的记忆。`iteration-XX-selection.json` 包含假设、验证样本差异及记忆结果。所有产物均不可覆盖。

验证样本具体轨迹和标识不进入下一轮 Refiner，只有未退化／退化原因和聚合数量回流。假设记忆当前只在同一演化任务的轮次间流转，不跨数据集或模型条件复用。

旧的 PG 默认实验和报告保留。新控制器的正式收益比较需要分别学习两张保留图，在之后新建、冻结的留出集上进行重复对照；生成图及 Profile 身份确定后，由现有实验契约生成逻辑冻结测试 `experiment-spec.json`。本阶段不伪造尚不存在的保留图身份，不宣称正式收益。
