# 复杂任务语义与修订闭环验证记录

## 性质与范围

本目录保存 2026-10-31 的开发集真实模型检查及所有中间负结果。使用已配置的 `openai_compatible / deepseek-flash`，调用经过现有 Model Gateway。每次运行保持最多 16 次模型调用、90 秒、既有上下文及 Token 预算；没有扩大预算来掩盖失败。

这是机制接入与修复验证，不是论文对照实验。没有 baseline/candidate 比较，没有 test split 调参或收益结论，也没有 promotion。少数任务通过不能保证任意复杂任务准确。

## 复现

两项单轮 smoke 使用既有开发数据集，保留原始任务文字：

```bash
venv/bin/python eval/run_adaptive_eval.py \
  --dataset research/experiments/request-recovery-smoke-v2/raw/adaptive-cases.json \
  --case R01 --case R02 --repeats 1 --max-samples 2 --max-model-calls-per-run 16 \
  --output output/complex-task-semantics/repeated-single-turn-report.json
```

跨轮任务固定在 `raw/followup-cases.json`。`capture_smoke.py` 调用同一真实评测器，并在隔离 SQLite 释放前保留副本供 UI 检查；它不替换模型或业务响应，不修改结果：

```bash
venv/bin/python research/experiments/complex-task-semantics-smoke-v1/capture_smoke.py --label new-followup-check
```

该命令会调用已配置模型。每个 label 只允许生成一次数据库与报告，避免覆盖负结果。数据库仅在被忽略的 `output/complex-task-semantics/` 下，未提交到仓库。

## 真实限制

普通对话目前只接入统一执行限制，尚未获得 Adaptive 的全量独立语义比较。提取和规划仍可能共同误解语言，协议修复也可能耗尽预算。聚合总预算等当前 Adaptive 目标无法表达的要求需要澄清，不能暗中转换为单件条件。完整上下文超预算时明确停止。后续仍需更大范围、多次重复及跨模型验证，不能用本轮单测或开发 smoke 代替准确率实验。
