# PG V6 状态转移预演实验

本实验只比较 `adaptive-pg-context-v4` 与 `adaptive-pg-preplay-v6`。两组绑定同一张 `pg-seed-v2` 图、相同定位器、类型化条件、确定性指导契约、模型、预算和任务集；唯一主要变量是是否启用有界状态转移预演。

候选机制最多预演三条边、保留四条 Beam 和四条候选路径。它只允许当前证据证明为 `TRUE` 的第一条边成为行动建议；后续边使用预测状态求值，并在真实工具结果返回后重新规划。预测状态不能写入目标账本、工具账本、Checkpoint 或验证结果。

离线契约 Gate：

```bash
venv/bin/python eval/run_pg_preplay_eval.py --gate
```

该 Gate 只证明搜索边界、未知传播、终态和弃权语义正确，不证明真实任务收益。真实收益必须按 `experiment-spec.json` 在冻结留出集上比较，并同时满足正确率、安全、协议及成本门禁；负结果保留。
