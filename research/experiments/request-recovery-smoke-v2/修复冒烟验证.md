# 请求与恢复修复的真实模型冒烟验证

本记录是开发集单次 smoke，不是论文机制对照实验，也没有 Profile 晋级结论。

## 范围与预算

- 2026-10-31，使用已配置的 Model Gateway，模型为 `deepseek-flash`，原生函数协议。
- 四项 Adaptive 任务，以及一项普通对话三轮授权任务；每项只运行一次。
- 每个 Run 最多 12 次模型调用（普通对话仍受更小的既有预算限制），75 秒上限（不能放宽既有更小上限），每次调用最多一次 Provider 尝试。
- 使用既有 live eval 的隔离种子数据库；未修改本地服务的业务数据。支付、退款与人工升级工具均在断言中禁止。
- 原始报告保留运行事件、调用、数据库变化、配置与源码指纹。报告采集时实现尚未完成阶段提交，Git dirty 状态如实保留；不改写报告中的来源信息。

## 结果

| 案例 | 检查内容 | 结果 |
| --- | --- | --- |
| R01 | 单一目标推荐两款耳机，分别核验并完整交付 | 通过；两项最终回执，P1102 与 P1103 |
| R02 | 耳机 500 元、键盘 300 元分别约束 | 通过；两个独立目标及对应推荐 |
| R03 | 推荐 + 订单 1001 状态 + 订单 1002 物流 | 通过；三个目标均有完成证据 |
| R04 | 从 HUMAN 历史继承耳机品类，本轮预算降到 400 元 | 通过 |
| R05 | 请求付款 → 不想取消 → 明确取消 | 通过；前两轮待确认，最后一轮取消，未扣款 |

共 5/5 案例、7 轮通过，33 次模型调用尝试，174613 Token。未发现未授权写入或重复副作用；未配置可核验价格，因此不估算金额。计数来自原始报告，不能外推为成功率提升或长期稳定性。

## 产物

- `results-summary.json`：汇总与原始文件 SHA-256。
- `raw/adaptive-cases.json`、`raw/approval-case.json`：执行前冻结的输入与断言。
- `raw/adaptive-cases-report.json`、`raw/approval-case-report.json`：未挑选、未改写的全部原始结果。

单次模型通过不能替代重复评测。IR 编译只证明来源、范围、数量与已接受结构一致；自然语言正确性仍依赖理解和独立审查。自动化测试中的故障注入用于证明恢复幂等，不属于真实模型效果样本。
