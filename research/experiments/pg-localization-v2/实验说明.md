# PG 轨迹状态定位实验 v2

本实验只改变 PG 的节点定位与局部子图检索：基线为 `adaptive-pg-context-v1`，候选为 `adaptive-pg-context-v2`。两者使用同一 Agent、程序图、指导 Prompt、模型、工具、核验器和运行预算。

离线机制契约运行：

```bash
venv/bin/python eval/run_pg_localization_eval.py --gate
```

该 Gate 不调用模型。它验证目标生命周期、跨图外动作恢复、完成态定位、低置信弃权和局部边预算。通过只说明实现符合定位契约，不说明真实任务成功率提升。

PG13 已经用于诊断 v1 的全图回退，属于设计已见样本。新的真实冒烟可以用它检查回归和事件链，但不得据此晋级机制或宣称论文收益。正式对照需要在 v2 实现冻结后建立新的 holdout；在此之前 `promotion_status` 始终为 `candidate`。

2026-10-24 的单样本真实诊断保存在 `diagnostic-smoke-2026-10-24.json`。v2 在 5 次干预中没有全图回退；最后一次干预的 v1 影子会回退全图，而 v2 仍定位到 `search_products`。样本最终因模型轮次预算耗尽而失败，并出现行动分歧，因此只证明定位行为变化，不证明任务收益。
